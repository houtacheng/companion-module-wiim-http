Hardware

Built for WiiM Mini, Pro, Pro Plus, Amp, Amp Pro and Ultra. In practice most LinkPlay-based devices work too, since they share the same interface — every command is a plain GET:

https://192.168.1.42/httpapi.asp?command=setPlayerCmd:vol:40
→ OK

https://192.168.1.42/httpapi.asp?command=getPlayerStatus
→ {"status":"play","vol":"40","curpos":"63634","totlen":"225000",…}
HTTPS first. Newer firmware answers only over HTTPS, with a self-signed certificate. Leave Protocol on Auto and the module tries HTTPS, then falls back to HTTP.

Finding the device

Three ways to point the connection at a device, in order of preference.

  1. Bonjour discovery

    Pick it from Discovered WiiM Device. Survives DHCP handing the device a new address.

  2. Manual address

    Type an IP or hostname. Simplest when the device has a reservation.

  3. Subnet scan

    Sweeps the networks your interfaces are on. A /22 is covered as four /24 blocks, so the device is found wherever in the range it sits. Pin it to one unit with Target Name / MAC / UUID.

What it controls

Transport

Play, pause, stop, toggle, next, previous, absolute and relative seek, play any URI.

Volume

Set, step, mute on/off/toggle, max volume ceiling, channel balance.

Sources

Network, Bluetooth, line in, optical, USB, coaxial, HDMI, HDMI ARC — plus next/previous stepping for encoders.

EQ

On, off, 24 named presets, bass and treble levels.

Device

Standby, wake, reboot, status LED, touch controls, shutdown timer, Bluetooth pairing, room correction.

Everything else

All 346 documented endpoints as a dropdown, either fire-and-forget or capturing the reply into api_last_* variables.

No confirmation step. Some documented endpoints are genuinely destructive — factory reset, network reconfiguration, firmware operations. A button press fires immediately.

Repeat and shuffle

The device packs both settings into one loop value, so there are six states rather than two independent switches. Version 1.5.0 corrected the mapping — the last column is what each value used to be labelled.

Mode Shuffle Repeat loop Was labelled
Off none 4 Repeat All
Repeat All all 0 Repeat Off
Repeat One one 1 unchanged
Shuffle none 3 Shuffle Repeat
Shuffle + Repeat All all 2 Shuffle
Shuffle + Repeat One one 5 Repeat Single
Each action changes only its own half. Because the two settings share one value, turning shuffle off used to reset the repeat mode as a side effect. It now carries the other setting across.

Media library

Companion can't open a native file picker inside a module, so the module reads a folder over HTTP and turns it into a file list you can drive from a button or an encoder.

Directory listing
Walked to a configurable depth from the base URL.
Index file
Any of files.txt, index.txt, playlist.m3u, index.m3u, files.json, index.json — or a URL you name.
Explicit list
Filenames typed into the config, comma- or newline-separated. Use this when the server returns 403 for listings.
Auto Random Next
Plays another random library file when the current one reaches its end. Off by default.
Assist Repeat One
Works around firmware that reports Repeat One for direct URL playback but never actually replays the file.

Fixed in 1.5

The 1.5 line is almost entirely corrections, several of which changed behaviour you may have worked around.

1.5.1

Preset button text showed $NA

Presets referenced variables through a this: scope that Companion does not define, so the text never resolved. They now use the connection's label. Re-add affected presets to pick up the fix.

1.5.0

Repeat and shuffle were inverted

Repeat: Off switched repeat-all on, and Repeat: All switched repeat off. Feedbacks saved against the old values keep their stored number and need reselecting.

1.5.0

Time variables were 1000× too large

curpos and totlen are milliseconds but were reported as seconds — a position of 63,634 ms rendered as 17:40:34 instead of 1:03.

1.5.0

Relative seek overshot the track

Seconds were added to a millisecond position, then sent to an API that expects seconds. Nudging forward 15s from 1:03 asked for second 63,649.

1.5.0

Some track titles became mojibake

Metadata arrives hex-encoded, and anything spelled only from a–f was decoded as bytes — so ABBA, cafe, Facade and bare years like 2024 came back as replacement characters.

1.5.0

Polls stacked and scans stampeded

With Auto Find on, every failed command started its own 254-host sweep, multiplied by overlapping polls. Rediscovery now shares one scan and backs off for 60 seconds.

1.5.0

Subnet scanning assumed a /24

Prefixes came from the interface address rather than its netmask, so on a /22 only one of four blocks was searched.

Install

  1. Download the package

    Grab wiim-http-1.5.1.tgz from the releases page.

  2. Import it

    In Companion: Modules → Import module package.

  3. Add the connection

    Search for WiiM HTTP, then point it at a device using one of the three methods above.

Or build from source

git clone https://github.com/houtacheng/companion-module-wiim-http
yarn install
yarn package  # → wiim-http-1.5.1.tgz

Built against WiiM's published HTTP API v1.2 and the OpenAPI description from cvdlinden/wiim-httpapi. Neither is redistributed here.
